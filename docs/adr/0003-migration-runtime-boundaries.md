# ADR-0003: runtime технической миграции

Дата: 15 октября 2026 года.

Статус: реализовано; итоговая приёмка миграции владельцем ожидается.

## Границы

- Единственный runtime расчёта — PHP 8.4/Symfony 7.4. Domain и Application не используют framework/Doctrine/storage SDK.
- Calculation содержит prototype-v0 геометрию и отдельно PrototypePricing. Это разделение ответственности внутри одного compatibility-контекста; будущий Pricing bounded context пока не создаётся.
- Денежные операции выполняются десятичной арифметикой BCMath с 18 знаками. Числа JSON старого контракта формируются только в HTTP presentation. Округление до целых копеек не вводится до утверждения ruleset-v1.
- Непроизводственные входы не объявляются производственно допустимыми. API проверяет форму и техническую вычислимость: 1–100 секций, конечные числа с модулем не более 1 000 000, тело до 64 KiB. Это ограничения транспорта, не новый мебельный ruleset. JSON Schema старого prototype-v0 сохранена для characterization; ограничения API описаны в OpenAPI.
- Типы frontend генерируются из OpenAPI; UI вызывает только HTTP gateway. Старый TypeScript engine изолирован в `src/compatibility/prototype-v0` за временным `VITE_ENABLE_PROTOTYPE_V0_FALLBACK`. Флаг по умолчанию выключен; default production build удаляет engine из bundle. Он сохраняется до подписанной parity как требует контрольная точка плана; автоматического fallback при ошибке API нет.
- Stateless endpoint не использует idempotency key: повторное вычисление не записывает данные. Correlation ID ограничен безопасным алфавитом и возвращается во всех ответах. ID будущих сущностей, даты UTC ISO-8601, pagination и idempotency записывающих операций будут описаны при появлении таких API; пустые API сейчас не создаются.
- Файлы приватны, вне web-root. Application получает opaque key и bytes; локальные пути известны только Infrastructure. В миграции доступны только техническая CLI probe и contract tests. Авторизованный download controller, ограниченные download references и пользовательская загрузка появятся вместе с Identity/документами после приёмки.
- PostgreSQL содержит только технические file metadata. FileStorage заменяем; ORM entity остаётся в Infrastructure. Смена local на S3 не требует изменения домена или use cases.
- web/API работают на одном origin через Nginx. GitHub Pages больше не является deploy-target: статический хостинг не может исполнять Symfony. CI собирает образы и проверяет локальный production-подобный стек; фактический production release требует отдельного выбранного окружения.
- PHPStan level 6 и Deptrac проверяют backend; Biome проверяет frontend без зависимости от несовместимых с TypeScript 7 версий typescript-eslint.

## Открытая точка parity

13 characterization fixtures проверяются полностью, текстовые/структурные значения совпадают. Максимальное наблюдаемое числовое отличие десятичного PHP pricing от бинарного TypeScript прототипа: `1.4551915228366852e-11` рубля. Оно не меняет отображаемую цену, но не является побитовым равенством.

Тестовый harness использует абсолютный допуск `1e-9` для совместимости числового JSON. Этот допуск — явно представленный результат на приёмку, а не утверждение об исполнении требования «любое отличие — дефект». До решения владельца parity не считается подписанным, миграция не считается принятой, продуктовый roadmap не начинается. Если требуется именно побитовое равенство, compatibility pricing нуждается в отдельном решении, согласующем его с запретом float для денег.
