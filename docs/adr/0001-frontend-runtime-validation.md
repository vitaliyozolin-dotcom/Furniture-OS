# ADR-0001: Zod для runtime-валидации frontend-контрактов

Дата: 28 августа 2026 года.

Статус: принято для технической миграции.

## Контекст

TypeScript проверяет типы только во время сборки и не гарантирует форму данных, полученных через будущий HTTP `CalculationGateway`. План миграции требует выбрать Zod либо Valibot и проверять ответы на runtime-границе.

## Решение

Использовать Zod в адаптерах frontend. UI и Zustand store не импортируют схемы валидации. Локальный compatibility adapter уже проверяет `prototype-v0` результат той же схемой, которая позднее будет применяться к HTTP-ответу.

## Последствия

- повреждённый или несовместимый ответ отклоняется до попадания в UI;
- схема остаётся на API-границе, а не становится второй доменной моделью;
- после появления OpenAPI generated types остаются compile-time контрактом, Zod — runtime-проверкой;
- замена библиотеки потребует изменения только gateway/adapters и их contract tests.
