# Furniture OS

Furniture OS сейчас находится на стадии UI-прототипа параметрического калькулятора корпусной мебели. Интерфейс демонстрирует один экран распашного шкафа и использует локальный расчёт; это ещё не готовый конструктор и не производственная система.

- React
- TypeScript
- Vite
- Vitest

## Локальный запуск

Требуется Node.js 22 и npm.

```sh
npm ci
npm run dev
```

## Проверки

```sh
npm test
npm run typecheck
npm run build
```

GitHub Actions выполняет эти проверки для pull request. Сборка ветки `main` дополнительно публикуется в GitHub Pages.

## Текущие границы

Первый продуктовый модуль посвящён распашному шкафу: геометрии, материалам, фурнитуре, предварительной стоимости, срокам и деталировке. Расчёт и интерфейс пока служат для проверки прототипа и не подтверждают производственную корректность или окончательную цену.
